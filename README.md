## Overview

PanMan is a creative auto-panning effect that models the circuit behavior of vintage hardware autopanners, with LFO shapes, tempo sync, audio-triggered panning, and vintage filter coloration.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys PanMan** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **LFO Shapes** | Sine, triangle, square, and random LFO waveforms for panning |
| **Audio Trigger** | Trigger panning movement from transients in the audio signal |
| **Vintage Coloration** | Analog-modeled filter response of classic autopanner circuits |
| **Tempo Sync** | Sync panning rate to DAW tempo with configurable beat divisions |
